# HCLab 仪器管理平台

为课题组 504 / 505 实验室设计的中文设备管理网站。前端适配 **GitHub Pages**，正式账号与数据已接入 **腾讯云 CloudBase 上海地域**。网站目前仅本地预览，尚未公开。

## 已实现

- 用户端仅保留工作台、仪器预约、记录查询；账户登录/注册/退出、站内通知。
- 独立管理员入口 `#/login?admin=1` 与后台 `#/admin`；公开注册不能创建管理员。
- 设备名称、型号、状态、项目归属、分类、负责管理员、504 / 505 房间、具体存放位置、开放日/时间、图片、说明和操作规程。
- 预设机器人本体、机器人传感器、工具；录入时可添加新分类；筛选项从设备动态汇总。
- 半小时粒度时段、申请审批、冲突阻止、取消、开始使用、续约、实际归还登记和通知。
- 完整中文条例初稿、30 题题库、随机 10 题、100 分满分合格、注册前一次性考试凭证。
- 违规阶梯：警告 → 1 周 → 1 个月 → 永久，保留违规与操作记录。

## 本地运行

推荐 Node.js 24 LTS。

```bash
npm ci
npm run dev
```

打开终端输出的本地地址。默认是**演示模式**，顶部明确提示；登录页提供普通用户和管理员体验入口。演示数据只在当前浏览器，不同步到其他用户；请勿录入真实密码或个人数据。自注册演示密码使用 PBKDF2 哈希存储，演示权限仍可由浏览器开发工具改写，不具有生产安全保证。

```bash
npm test
npm run build
npm run preview
```

## 正式部署

当前环境配置和维护见 [CloudBase 接入说明](docs/CLOUDBASE.md)。生产模式没有默认管理员密码，也没有演示切换入口。原 [Supabase 部署说明](docs/DEPLOYMENT.md) 保留为备选方案。

当前**网站已取消公开发布，源码仓库保持公开**：[GitHub 仓库](https://github.com/HCLab-gz/HCLab-Equipment-Management) · [提交 issue](https://github.com/HCLab-gz/HCLab-Equipment-Management/issues)。本地可使用 `npm run dev` 继续评审。

推送 `main` 只测试和构建，不会发布网站。未来确认需要公开时，由维护者手动运行 Actions 并明确勾选 `publish`。如需再次下线，由仓库管理员在 Settings → Pages 中取消发布，操作说明见部署文档。

未配置后端的新安装默认运行演示模式；本机已配置 CloudBase，注册、满分考试、预约及管理操作保存到云端。原浏览器演示记录不会导入正式库。

## 使用约定

- 所有时间按北京时间处理；一个申请限同一天，跨日分开申请。
- 待审批申请暂占时段；管理员驳回或申请人取消后释放。批准前不能使用。
- 开始使用必须在已批准时段内；上一位尚未归还时禁止下一位登记开始使用。
- 续约是紧接原预约结束时间的新申请，需另行批准，不能提前改变原时限。到续约起始时间后，在新记录上点击“开始 / 衔接续约”，系统原子衔接本人仍在使用的原预约，保留交接记录，不虚构物理归还。
- 到期不会自动算作归还，管理员可依据超时与领用记录核实违规。
- 准入限制作用于本平台预约与开始使用。**系统没有连接实体门禁**，由管理员同步执行。
- 数据默认每 30 秒刷新，切回窗口时也刷新；提交时由服务器再次核验。

## 条例来源与待核对内容

界面结构参考 [HKUST(GZ) 仪器展示页面](https://instrumentsharelab.hkust-gz.edu.cn/Equipment/ShowList?XPath=000)。条例已从[原腾讯文档](https://docs.qq.com/doc/DWG12Z0hhcmd5ZGFP) 提取全文，并合并课题组补充要求。注册页和条例页直接展示 6 个通用章节与 G1、Oli、Tron1、Franka、Lift2 的 5 个设备章节，支持目录定位、折叠与展开；[提取原文存档](docs/lab-rules-source.md) 保留对照。原文的纸质登记要求已调整为平台预约与归还流程。正式启用前，请课题组确认条例文本及损失责任处理依据。

演示设备、型号、项目、位置、账号和预约为示例，不是已经核实的实验室资产清单。生产数据库迁移**不导入示例资产**，由管理员录入真实设备。

## 代码结构

`src/pages/` 页面，`src/lib/` 数据适配与业务规则，`src/data/` 条例与演示内容，`cloudbase/migrations/` 正式数据库迁移，`cloudbase/functions/` 注册云函数，`supabase/migrations/` 备选后端迁移，`tests/` 与 `cloudbase/database.test.ts` 为业务、配置及权限测试。

数据库测试使用 PGlite 运行真实 PostgreSQL SQL（包括 RLS 与 RPC），分别模拟 CloudBase 和 Supabase 的身份结构。CloudBase 注册、登录、考试、并发预约、审批及通知已在真实环境验证；详见 [实施记录](docs/cloudbase-integration-plan.md)。
